# Deeping-in-java

A repository dedicated to deepening my knowledge of Java through hands-on practice, problem-solving, and experimentation.

The repository is organized into two main directories:

- **`leetcode/`** – Solutions to LeetCode problems implemented in Java, focusing on improving problem-solving skills, algorithmic thinking, and data structures.
- **`java-topics/`** – In-depth exploration of Java concepts, including practical examples, performance benchmarks, memory management, collections, concurrency, and other language features.

The goal is to go beyond simply learning Java syntax and understand how things work under the hood through code, experiments, and performance analysis.
